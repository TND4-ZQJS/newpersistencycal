Output Format (CSV):
PolicyNo, AgentName, ClientName, MonthsPaid, PsistANP, Status, PremiumDueDate, PersistencyBlock, ReportDate

Extraction Rules:
1. ONLY return the plain CSV lines. Do NOT include markdown code blocks (```), introductory text, explanations, or column header lines in the final output.
2. Only include actual individual policy rows (skip page headers, sub-totals, section titles, or summary rows like "Policy Cnt / Total ANP").
3. Extract every policy row regardless of sub-headings (e.g. "OL", "RPIL", or other issue-type groupings).
4. PersistencyBlock = The date range near the top of the report (e.g., "01-JUN-2023 to 31-MAY-2024"). Repeat this exact value on every row.
5. ReportDate = The report date in the top corner (e.g., "11/07/2025"). Repeat this exact value on every row.
6. Number Formatting: Remove ALL commas/thousand separators from numeric amounts (e.g., use 3600.00, NOT 3,600.00). Keep exact decimal values.
